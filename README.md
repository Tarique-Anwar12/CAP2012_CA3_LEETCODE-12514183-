# CAP2012 CA3 - LeetCode C++ Solutions

This repository contains the 16 problems listed in the CA3 assignment, organized into Easy, Medium, and Hard folders.

## Important
- These are LeetCode submission-style C++ solutions. LeetCode supplies common headers and the `ListNode` definition for linked-list questions.
- For local compilation, add `#include <bits/stdc++.h>` and `using namespace std;` at the top. For linked-list questions, also define `ListNode` as required by your local test program.
- Test each solution on LeetCode, including edge cases, and make sure you can explain the approach and complexity in your viva.
